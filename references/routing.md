# Routing Rules

Add this to a project's `CLAUDE.md` or `AGENTS.md`:

```markdown
## GStack Validation Companion routing

- Startup idea or "is this worth building?" -> /office-hours
- Approved startup-mode Office Hours design -> /validation-plan
- Prepare or conduct one founder-led validation repetition -> /customer-reps
- Interpret experiment evidence or decide what to change -> /validation-review
- Turn proven founder-led distribution into a repeatable system -> /distribution-loop
- Build a landing page only when /validation-plan identifies it as the cheapest credible test -> /buyable
- Do not route startup ideas directly into implementation planning before a validation decision explicitly advances them.
```
