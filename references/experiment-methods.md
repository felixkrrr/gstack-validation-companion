# Experiment Selection

Choose based on the riskiest uncertainty:

- Buyer unclear: founder-led discovery conversations.
- Workflow or pain unclear: workflow mapping and problem interviews.
- Buyer and pain clear, response unclear: founder-led outbound.
- Trust-heavy or integrated product: design-partner recruiting.
- Value can be delivered manually: concierge pilot.
- One painful workflow can be isolated: narrow-workflow pilot.
- Message unclear but buyer understood: mock demo or buyable surface.
- Commitment unclear: pre-sell, deposit, or paid pilot.

A landing page is not the default. It is credible only when the founder already
knows who should see it, can distribute it to those people, and knows which
action would represent meaningful pull.

Before interpreting a result, ask:

1. Did the experiment reach the intended people?
2. Was the offer and ask understandable?
3. Was the repetition performed with enough care and volume?
4. Could execution quality explain the result?
